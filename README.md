# Design Reference Hub

바이브코딩으로 웹페이지나 프로그램 화면을 만들기 전에 참고할 디자인을 찾는 사이트 11곳을 한 화면에 모은 벤토그리드 페이지.

- 정적 페이지: `index.html` 한 장(빌드 없음) → Vercel 배포
- 디자인: design-ref-finder 스킬로 고른 **A. 비비드 투톤 벤토** (주황 `#FF6A1A` · 하늘 `#8EB4F6`), 기준 레퍼런스 Spline 커뮤니티 "Bento 3D"
- 디자인 결정 기록: `design-refs/2026-11-21-bento-hub/` (`board.json` 추천 보드, `brief.md` 디자인 브리프)
