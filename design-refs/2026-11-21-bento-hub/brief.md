# 디자인 브리프: 디자인 레퍼런스 허브 (벤토그리드)

- 작성: 2026-11-21 · design-ref-finder
- 고른 방식: **A. 비비드 투톤 벤토**
- 참고 레퍼런스: Spline 커뮤니티 **Bento 3D** (krisxsee) — https://app.spline.design/community/file/1aee2576-f38c-4f84-8140-aea0b3f5bb9a
  - 애플 iPhone 16e 발표에서 영감을 받은 3D 벤토 타일. 해시태그: #Bento #Apple #Liquid #Chip #Particles #Light #Shadows #Gradient #3D
  - 가져올 점: 타일이 살짝 떠 있는 입체감(그림자·빛 번짐), 타일 하나를 3D 오브젝트로 채우는 구성
- 첨부 이미지 1(주황·하늘색 음식앱 벤토): 색·라운드·굵은 글씨의 기준

## 목적
design-ref-finder 스킬이 안내하는 디자인 레퍼런스 사이트 10곳을 한 페이지에서 보고 바로 들어갈 수 있게 한다. 정적 페이지(HTML·CSS·JS 한 벌), GitHub `roughkyo/design_reference` → Vercel 배포.

## 색
| 이름 | hex | 쓰임 |
|---|---|---|
| Orange | `#FF6A1A` | 주요 타일 배경, 강조 |
| Sky | `#8EB4F6` | 보조 타일 배경 |
| White | `#FFFFFF` | 타일 속 카드, 글자(주황·하늘 위) |
| Ink | `#111111` | 페이지 바탕(타일 사이 검은 틈), 본문 글자 |
| Peach | `#FFE3D1` | 연한 타일, 배지 바탕 |
- 타일 사이 틈 12~16px, 바탕은 Ink.

## 글꼴
- 제목(영문·숫자): Unbounded 700~800 (넓고 굵은 형태, 첨부 1 제목 느낌)
- 본문·한글: Pretendard 400~700

## 모양·간격
- 타일 모서리 28px, 타일 속 카드 18px, 배지 999px
- 타일 안쪽 여백 24~28px
- 그림자: 타일 자체는 평면, 타일 속 흰 카드에만 `0 10px 30px rgba(0,0,0,.18)`
- 3D 느낌: 히어로 타일의 큐브 묶음(CSS 3D)에 빛 번짐(radial gradient)과 부드러운 그림자. Bento 3D처럼 은은한 반짝이(입자) 몇 개

## 움직임
- 타일 호버: 2px 위로 + 화살표 ↗가 대각선으로 4px 이동(0.2s)
- 히어로 3D 큐브: 천천히 회전, 사용자가 '움직임 줄이기' 설정이면 멈춤
- 필터를 누르면 해당 없는 타일은 흐리게(opacity .25)

## 화면 구성 (데스크톱 4열, 태블릿 2열, 모바일 1열)
1. **히어로(2×2, 주황)**: "DESIGN REFERENCE HUB" + 한 줄 설명 + 3D 벤토 큐브
2. **숫자 타일(하늘)**: 10 Sites · 무료 8 · 로그인 2
3. **필터 타일**: 전체 / 웹 / 프로그램 / 무료 / 로그인
4. **사이트 타일 10개**: 역할(작은 대문자) · 사이트 이름(굵게) · 한 줄 설명 · 열람 배지 · 웹/프로그램 표시 · ↗
   - 크기 섞기: Spline·21st.dev 2×1, 나머지 1×1. 주황·하늘·피치·흰 타일을 번갈아
5. **사용법 타일(2×1, 피치)**: design-ref-finder 4단계(상황 → 방식·레퍼런스 → 보드에서 고르기 → 브리프)
6. **푸터 타일(4×1, 주황)**: 만든 날짜·GitHub 링크

## 바이브코딩 프롬프트
"정적 HTML 한 장으로 '디자인 레퍼런스 허브' 벤토그리드 페이지를 만들어 줘. 바탕은 #111, 타일은 주황 #FF6A1A·하늘 #8EB4F6·피치 #FFE3D1·흰색을 번갈아 쓰고 모서리 28px, 틈 14px. 제목은 Unbounded 800, 본문은 Pretendard. 첫 타일(2×2)은 Spline 'Bento 3D'처럼 빛이 번지는 3D 큐브 묶음을 CSS로 넣고 천천히 회전. 사이트 타일 10개에는 역할·이름·한 줄 설명·무료/로그인 배지·↗를 넣고, 상단 필터(전체·웹·프로그램·무료·로그인)로 해당 없는 타일을 흐리게. 데스크톱 4열·태블릿 2열·모바일 1열."
